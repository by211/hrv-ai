# Phone screenshots

These screenshots were captured from the release-equivalent debug build on a
Pixel 6a Android virtual device running API 36. They are accurate 1080 × 2400
PNG captures and can be uploaded to the Google Play phone screenshot slot
before the app is published.

2. `02-sensor-diagnostics.png` — Sensor connection diagnostics.
3. `03-calibration.png` — Guided multi-rate calibration setup.
4. `04-settings-privacy.png` — Local data controls and privacy-policy link.

Replace or supplement these with physical-device captures only if the final
release UI materially changes.
